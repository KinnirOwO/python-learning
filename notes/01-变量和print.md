# 变量和 print()

## print()：把内容显示出来

```python
print("Hello")        # 输出：Hello
print(1 + 2)          # 输出：3
print("a", "b", "c")  # 多个内容用逗号隔开，输出时中间自动加空格
```

## 变量：给数据起个名字

```python
age = 18          # 整数 int
height = 1.75     # 小数 float
name = "小明"      # 字符串 str，要加引号
```

- `=` 是"赋值"，意思是把右边的值放进左边的名字里，不是数学里的"等于"
- 变量名只能用字母、数字、下划线，不能以数字开头
